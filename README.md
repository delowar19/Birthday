# For Jannu — Birthday Website

## Preview
Open `index.html` in a modern browser. Keep the `assets` folder next to it.

## Included
- Cinematic black / neon pink / purple styling
- Animated stars and intro
- Live countdown to the next November 6 (local device time)
- Jannu's uploaded black-and-white photo
- Click-to-open bilingual English/Bangla letter
- Photo-only cinematic final reveal (no video)

## Customize
Replace `assets/jannu-photo.jpg` with another photo if you want, keeping the same filename. Edit the letter and captions directly in `index.html`.

## Share it online
For a public link, upload the whole folder to a static hosting service such as Netlify Drop or GitHub Pages. Upload `index.html` and the complete `assets` folder together; do not share the HTML alone.

This is a static website; no account, database, backend, or video file is required.
